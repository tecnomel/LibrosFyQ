Las cuatro reglas de las potencias de 10

1. Multiplicar: se SUMAN los exponentes

10a · 10b = 10a + b
103 · 104 = 103+4 = 107  ·  105 · 10-2 = 105+(-2) = 103
Con números delante: se multiplican los números y se suman los exponentes.

2. Dividir: se RESTAN los exponentes

10a / 10b = 10a − b
107 / 103 = 107−3 = 104  ·  102 / 10-3 = 102−(−3) = 105
exponente de arriba menos exponente de abajo

3. Subir o bajar: se CAMBIA el signo

110b = 10−b
1103 = 10-3  ·  510-2 = 5 · 102
Una potencia de 10 puede subir o bajar de la raya de fracción si su exponente cambia de signo.

4. Potencia de una potencia: se MULTIPLICAN

(10a)b = 10a · b
(102)3 = 102·3 = 106  ·  (10-3)2 = 10(−3)·2 = 10-6
Se usa para cambiar unidades de superficie (²) y de volumen (³).
