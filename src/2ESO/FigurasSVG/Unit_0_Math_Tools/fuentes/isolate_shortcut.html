Two ways of isolating: both give the same result

Method 1: the same on BOTH sides

Do the opposite operation on both sides of the equation.
it is adding (+ 3)→subtract 3 on both sides
it is subtracting (− 3)→add 3 on both sides
it is multiplying (· 3)→divide both sides by 3
it is dividing (/ 3)→multiply both sides by 3
x + 3 = 7
x + 3 − 3 = 7 − 3
x = 4

Method 2: it “goes to the other side”

It changes side and does the opposite operation.
adding⇄goes subtracting
subtracting⇄goes adding
multiplying⇄goes dividing
dividing⇄goes multiplying
x + 3 = 7
x = 7 − 3
x = 4
