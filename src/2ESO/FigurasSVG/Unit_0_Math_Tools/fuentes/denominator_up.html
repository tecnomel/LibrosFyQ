If the unknown is below the line, first bring it UP

✘ Wrong way: we get 1/x, not x

1
Equation (we want x).
5 = 20x
2
We divide both sides by 20 (the 20 “goes dividing”).
520 = 1x
?
x is still below the line: we have 1/x, not x. It is not isolated!
1x = 0,25

✔ Right way: bring x up first

1
Equation (we want x).
5 = 20x
2
x is dividing: it goes to the other side multiplying (now it is up).
5 · x = 20
3
5 is multiplying x: it goes to the other side dividing.
x = 205 = 4
When the quantity we want is in the denominator, the first step is always to multiply both sides by it (it “goes up multiplying”). Then we isolate it as usual.
