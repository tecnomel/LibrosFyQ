Analysing a straight-line graph

1. Where does it start? At x = 0 the line is at y = 5 (if it starts at 0, it passes through the origin).
2. Does it go up or down? It goes up: when x increases, y increases.
3. How steep is it? The slope
slope = ΔyΔx = yB − yAxB − xA = 104 = 2,5
For each unit of x, y increases 2,5.

goes up: positive slope

goes down: negative slope

horizontal: slope 0 (y does not change)

steeper = bigger slope
