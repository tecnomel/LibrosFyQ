Cómo analizar una gráfica de línea recta

1. ¿Dónde empieza? Para x = 0 la recta está en y = 5 (si empieza en 0, pasa por el origen).
2. ¿Sube o baja? Sube: cuando x aumenta, y también aumenta.
3. ¿Cuánto se inclina? La pendiente
pendiente = ΔyΔx = yB − yAxB − xA = 104 = 2,5
Por cada unidad de x, y aumenta 2,5.

sube: pendiente positiva

baja: pendiente negativa

horizontal: pendiente 0 (y no cambia)

más inclinada = mayor pendiente
