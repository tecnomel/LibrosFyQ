Diamante (C)

Cada C se une a 4 C formando tetraedros en las tres direcciones del espacio: muy duro, no conduce.

Grafito (C)

Cada C se une a 3 C formando capas de hexágonos; las capas se unen débilmente: blando, conduce.

Cuarzo (SiO₂)

Cada Si se une a 4 O y cada O a 2 Si: red tridimensional, muy duro.
